# 0Rzxn_ Launcher 0.3.2

## English

- **Fewer false alerts before launch.** Some NeoForge mods carry the libraries they need inside their own file. The pre-launch check now finds them, so it no longer reports them as missing dependencies.
- **Mods made for another loader.** A Fabric mod in a NeoForge instance (or the other way round) is now flagged before launch, since the game would never load it.

## Français

- **Moins de fausses alertes avant le lancement.** Certains mods NeoForge emportent dans leur propre fichier les bibliothèques dont ils ont besoin. Le diagnostic avant lancement les trouve maintenant et ne les signale plus comme des dépendances manquantes.
- **Mods faits pour un autre loader.** Un mod Fabric dans une instance NeoForge (ou l'inverse) est maintenant signalé avant le lancement, puisque le jeu ne le chargerait jamais.

## Español

- **Menos falsas alertas antes de iniciar.** Algunos mods de NeoForge llevan dentro de su propio archivo las bibliotecas que necesitan. La comprobación antes de iniciar ahora las encuentra y ya no las marca como dependencias que faltan.
- **Mods hechos para otro cargador.** Un mod de Fabric en una instancia de NeoForge (o al revés) ahora se señala antes de iniciar, ya que el juego nunca lo cargaría.
