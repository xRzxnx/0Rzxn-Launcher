# 0Rzxn_ Launcher 0.6.0-beta.1

## English

- **Linux and macOS (experimental).** The launcher now runs on Linux (AppImage, x64) and macOS (dmg for Apple Silicon and Intel). See the README for the first launch: `chmod +x` and FUSE 2 on Linux, **Open Anyway** in System Settings › Privacy & Security on macOS, since the app isn't signed by Apple.
- **Updates.** On Linux the AppImage updates itself. On macOS the launcher tells you when a new version is out and opens its page.
- **Apple Silicon.** Minecraft versions older than 1.19 run with Intel Java through Rosetta. If Rosetta is missing, the launcher gives you the command to install it.
- **Linux without a keyring.** Without GNOME Keyring or KWallet, your Microsoft session stays in memory only and is never written to disk: you sign in again at each start.
- **Stop.** Stopping a game that no longer responds now works on every system.
