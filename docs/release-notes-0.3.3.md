# 0Rzxn_ Launcher 0.3.3

## English

- **The Crystal menu is now on by default in modded instances.** The first time you launch a Fabric, Forge, NeoForge or Quilt instance, the launcher adds FancyMenu and the mods it needs from Modrinth, then opens the game on the Crystal title screen. Instances you already set up are left as they are.
- **You stay in control.** In the instance settings, "Keep the classic menu" stops it from being added, and the launcher remembers that choice. Instances with a mod known to crash with FancyMenu are skipped, and the settings explain why. Vanilla instances don't change.

## Français
