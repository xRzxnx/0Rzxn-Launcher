# 0Rzxn_ Launcher 0.5.1

## English

- **Beta channel.** Settings › Launcher › Updates has a new "Get beta versions" switch, off by default. With it on, the launcher also receives beta versions before everyone else. Turning it off keeps the beta you have until the next stable version arrives on its own.
- **Releases built by GitHub Actions.** Every installer is now built from the public source code on GitHub's servers and checked on VirusTotal before it is published (the report is linked below). Code signing through SignPath Foundation is on its way: see the code signing policy.

## Français

- **Canal bêta.** Paramètres › Launcher › Mises à jour a un nouvel interrupteur « Recevoir les versions bêta », désactivé par défaut. Activé, le launcher reçoit aussi les versions bêta avant tout le monde. Le désactiver garde la bêta installée jusqu'à ce que la prochaine version stable arrive toute seule.
- **Versions construites par GitHub Actions.** Chaque installateur est maintenant construit depuis le code public sur les serveurs de GitHub et contrôlé sur VirusTotal avant d'être publié (le rapport est en lien ci-dessous). La signature du code par la SignPath Foundation est en cours : voir la politique de signature.

## Español

- **Canal beta.** Ajustes › Launcher › Actualizaciones tiene un nuevo interruptor «Recibir versiones beta», desactivado por defecto. Activado, el launcher también recibe las versiones beta antes que nadie. Al desactivarlo, conservas la beta instalada hasta que la próxima versión estable llegue sola.
- **Versiones creadas por GitHub Actions.** Cada instalador se crea ahora a partir del código público en los servidores de GitHub y se comprueba en VirusTotal antes de publicarse (el informe está enlazado abajo). La firma del código por la SignPath Foundation está en camino: consulta la política de firma.
